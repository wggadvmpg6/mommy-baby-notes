# 在高平公立医院申请供卵做试管都是什么流程？

> 更新时间：2026-09-10 (UTC+8)

我是2019年的时候在我们高平市的人民医院查出来的不孕症，当时医生说是没有卵子，建议我去公立医院做供卵试管，当时有点害怕就没多问。直到现在，一家人才商量好了结果，打算先咨询咨询，然后就去高平的公立医院做供卵试管。我想问问各位朋友做供卵试管需要什么手续？申请供卵做试管婴儿的流程又是怎样的？

目前高平市没有做供卵试管的医院，高平市妇幼保健院、高平市人民医院以及高平市中医院等等这些公立医院，都没有开展辅助生殖技术，所以无法在高平申请供卵做试管。有供卵需求的患者建议前往同省的太原市，那边有做供卵试管的医院。而申请供卵做试管的流程就是男女双方都先要做检查，评估是否符合供卵的条件，若是符合，女方就可以按血型登记等待卵源了，男方此时可以取精，把精液冷冻备用。等到卵源后，就建病历，签署受卵知情同意书，然后就解冻精液、体外受精、胚胎培养以及移植。

虽然高平市目前没有做试管的医院，但是同省的太原市有，位于太原市的山西省妇幼保健院和山西省生殖遗传医院等，都是可以供卵做试管的。这些医院做供卵试管的流程几乎一样，下面就给大家介绍一下申请供卵做试管的具体流程：

- 1. 准备好三证（结婚证、身份证、准生证），前往可以供卵做试管的医院，夫妻双方进行IVF术前检查，评估是否有受卵适应症，若是符合，女方就可以按血型登记等待卵源了，男方此时可以取精，把精液冷冻备用；
- 2. 然后就是等待卵源，卵源来自于正在该医院接受试管治疗的不孕患者，在取卵日有符合赠卵条件的卵源，由手术室护士通知临床医生，术后与患者沟通赠卵事宜；
- 3. 明确赠卵后，临床医生通知档案室病历管理负责人，按照冷冻精液顺序及血型符合原则，选择配对的受卵患者，并电话沟通确认；
- 4. 确认后填写受卵者男方精液解冻通知单，交给实验室，解冻受卵者精液，进行授精、胚胎培养、胚胎冷冻，并按胚胎冷冻顺序，提供受卵患者的病历号；
- 5. 胚胎冷冻半年后，由档案室病历管理专人电话通知赠卵者复查感染相关指标，明确没有感染后，告知临床医生；
- 6. 临床医生可按期联系受卵患者来院行冻胚移植。
一般来说，申请供卵做试管的流程里面，等待卵源是需要很长一段时间的，大概3-5年。所以建议要申请供卵做试管的患者尽早去医院登记，男方最好也先取精，把精子冷冻起来，以备日后使用。
