# 【“人民”喜讯】青年教师赵一馨荣获全国高校青年教师教学竞赛决赛一等奖

> 更新时间：2026-09-11 (UTC+8)

//  

2023年4月20至24日，由中华全国总工会和教育部联合主办的第六届全国高校青年教师教学竞赛决赛在清华大学举办。

**北京大学人民医院青年教师赵一馨作为北京队医科组选手参赛，****荣获全国一等奖。**

本次竞赛共有1800多所高校的近50万名青年教师参加了院、校、市、省等多层级的比拼，最终来自31个省和新疆生产建设兵团121所高校的158名教师进入了决赛。竞赛设置文科、理科、工科、医科、思想政治课专项共5个组别，以“上好一堂课”为理念，要求每名选手在赛前提交参赛课程的教学大纲、16个学时的教学设计方案和对应的课堂教学阶段PPT。决赛阶段，由选手现场随机抽取一个教学节段，进行模拟课堂教学并撰写教学反思，考验了青年教师教学基本功素养，展现出当代青年教师风采。

本届比赛是北京大学人民医院青年教师首次闯进全国决赛，在北京市教育工会的大力支持下，北京大学医学部、人民医院高度重视，校、院两级工会与教育处通力协作，制定细致的整体备赛计划，精准把控备赛细节。

经过周密细致的准备，来自医院耳鼻咽喉头颈外科的赵一馨携16节精心准备的《耳鼻咽喉科学》课程登上全国比赛的舞台，在决赛现场稳定发挥，以优异的表现赢得了评委的赞许与选手的尊重，最终摘取全国一等奖的好成绩。

北京大学人民医院始终高度重视教育教学工作和青年教师基本功培养。从1985年开始，医院举办青年教师教学基本功比赛，至今已经开展了28届，成为医院临床教学品牌项目，成为深化教育教学改革、提高教学水平的有效手段，更是成为激励青年教师快速成长、展现青年教师才华的宽阔舞台。

这项活动使一批年轻教师脱颖而出，目前已成为医院学术带头人以及中坚力量，并诞生了数十名北京市和北京大学青年教师教学基本功比赛获奖教师，对于促进医院青年教师教学水平的整体提升，营造良好的教学环境起到引领和推动作用。

医学教育承载着民族的希望和未来，青年临床教师是塑造民族希望和未来的践行者，是“为党育人”“为国育才”的新生力量。

未来，医院将继续广泛开展师资培训，提供完备的培养体系，打造医院教师交流平台，聚焦立德树人的根本任务和教书育人的职责使命，切实提高全院教师在课程思政、理论授课、临床实践、教育教学研究等各方面的教学能力。医院大力营造教师热爱教学、投身教学的良好氛围，打造一支优秀教学团队，使医院临床教学工作焕发出新的生机和活力！

**选手心语**

在一年多的“国赛”筹备过程，也让青年教师赵一馨成长颇多、感触颇多，让我们一起听听她的备赛经历——

作为一名青年教师，我有幸参加了第六届全国高校青年教师教学竞赛，这成为我人生中一次重要的历练。历时1年零9个月的筹备，历经数百次试讲、演练，近10万字的逐字讲稿，20余万字课程教案，近千页ppt，300余GB的课程材料，50余件贴近课程所制作的教具、展板……所有的一切一切，都在我成长道路上留下了不可磨灭的印记。

还记得初期选题时，为了22个讲课内容的选取，我重新梳理了《耳鼻咽喉科学》教学大纲和课程安排，选取兼具临床实践与理论深度的教学内容，通过备课、试讲、修改来回打磨，优中选优，并利用休息时间广泛阅读整理课程相关文献，形成教学思路，编写教学设计，修订教案，对每一部分的重难点有了更全面和准确的把握。

在整个比赛过程中，我有幸得到了许多资深名师和前辈专家及同事的热情指导与帮助，也与其他青年教师进行了宝贵的交流。学校、学院邀请相关领域专家组成辅导团队全程辅导，精修课程教案、推敲授课思路、打磨课件设计，对每个课程细节从严把控、认真研讨、仔细研磨。从整个教学内容的选取和设计是否合理、清晰，到每个知识点的阐述是否准确、易懂；从讲课时的仪表仪态、手势语言，到习惯性的口头禅和小动作，老师们都提出了很多宝贵的意见建议。耳鼻咽喉头颈外科内部隔周的小讲课几乎成了我的训练场，在这里将新思路、新设计展示给科内老师，再带着老师们详细的修改意见回去返工，如此循环往复。同时，我把自家客厅改造为讲台，每天都坚持讲四五个题目，动员亲友团线上听课，来自各行各业、不同专业的数十位亲友都成为了我的听众，提出了中肯的建议。

千尺之台起于垒土，千里之行始于足下，1年零9个月的时光飞逝，点滴努力也获得了回报。在不断完善自己的过程中，我愈发体会到“教师”二字意义之深远。非常感谢医院、科室以及每一位帮助我备赛的老师朋友，作为一名新时代的青年教师、青年医生，我将不忘立德树人初心，牢记为党育人、为国育才使命，积极探索新时代临床教学方法，不断提升临床教学本领。在从教从医路上，向光而行，用拼搏与奋斗描绘出青春最美的样子。
