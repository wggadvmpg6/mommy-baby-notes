# 预约开始啦！冬病冬治——快来贴“三九贴”

> 更新时间：2026-09-16 (UTC+8)

“三九”即为二十四节气“冬至”后的3个“九天”，是一年中最为寒冷的时期，此时人体阳气内藏，气血不畅，皮肤干燥，毛孔闭塞，易患疾病。“三九贴”是指在每年“三九”的寒冷季节中用中药外敷于人体特定的穴位，以达到祛除和预防疾病的一种中医传统外治疗法。

**1**

**“三九贴”有何功效**

“三九贴”可疏通经络，调理气血，宽胸降气，健脾和胃，鼓舞阳气，调节人体的肺脾功能，使机体的免疫功能不断增强，从而达到振奋阳气，促进血液循环、祛除寒邪、提高卫外功能的效果。

**2**

**“三九贴”最合适调理的对象**

1. 容易感冒、发烧、冬季易患肺炎，哮喘，支气管炎，反复咳嗽的孩子。

2. 中焦虚寒、虚寒性胃病、胃肠功能紊乱、虚寒腹泻的孩子。

3. 过敏体质、过敏性鼻炎、慢性荨麻疹、腺样体肥大的孩子。

**“三九贴”注意事项**

1. 贴敷时间：儿童1-2小时，如有不适者可随时拿掉。

2. 贴敷对象：最好是2岁以上儿童。

3. 禁忌人群：贴敷部位有破损者，疾病发作期，如正发烧、咳喘等。

4. 贴药后，部分患者局部出现温、热、辣等感觉，属于药物吸收的正常反应，大多可以忍受，如果实在难以忍受，请立刻拿掉。

5. 贴敷期间，如起水泡，应注意保护创面，避免感染，必要时请到医院就诊，及时处理或涂擦烫伤膏。
